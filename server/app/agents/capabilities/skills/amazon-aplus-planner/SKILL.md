## professional-aplus-v2 模块设计
本节只适用于A+且本轮amazon_brief_contract=professional-aplus-v2；Listing和旧简报保持各自原有契约，不套用Basic模块数量或槽位要求。
默认Basic；用户说专业或高级感不代表Premium资格。明确Premium需求时核对账号适用性，未接Seller Central只能记录运营确认，不能声称平台已验证开通。
普通完整Basic优先五模块，最多五；Premium最多七且不能与Basic混用。五是默认叙事建议，不是固定五张图；少量主题或用户指定范围可改变数量并说明完整叙事依据。每模块必须选择当前amazon_rules里的真实spec_id，不机械复用overlay横幅。优先组织“建立识别→回答购买问题→细节证据→使用关系→情感价值”的适合本商品的叙事，不把未确认定制或性能补成卖点。
布局应有节奏：header大幅主视觉、side-image左右图文、three-image多图文及必要overlay等按目的组合；避免连续重复中景人物+背景。每模块的art_direction明确framing（镜头角度、景别、主体占比/位置）、lighting（主光方向、软硬、补光与反差）、hierarchy（第一/第二视觉焦点、文字与图像关系）、integration（比例透视、接触阴影、遮挡与真实布料受力）。每项简洁20–50字，不重复共享锁。
design_principles选实际采用的规则：product_identity商品保真、campaign_consistency整套风格、visual_hierarchy焦点层级、commercial_lighting商业布光、scale_context人物/环境尺度、detail_truth真实细节证据、emotional_story有目的的情绪场景、copy_separation原生文字分离、multi_slot_storytelling多槽位分工。至少三项，并在art_direction/构图实际落实，不能只填标签。
多图模块的image_slots必须按规则slot id分别设计独立画面与对应文案。例如三图文的block1/2/3应分别回答不同问题、采用不同景别；每个槽位单独生成，不把三图拼在一次模型输出中。不要填模型猜测的像素尺寸，按当前规则生产。商品颜色、Logo、号码和图案仍锁定原参考；新营销文案由原生文字排版，图片内不生成小字。

## Listing与公司六类方向
Listing使用deliverable=listing，按需求选纯白底white、定制custom、观赛watch、礼品gift、细节detail、休闲casual，不强制六张。spec_id=listing_square，比例/尺寸优先用户明确值。定制细节横版属于detail变体，礼品背面属于gift变体，不创建重复分类。不要求实体模板库，可自由设计新构图。
图A/B/C职责和有效定制值由company_visual_rules定义，按本次明确素材角色读取。图C只管字体轮廓，不能把0/00占位覆盖实际姓名号码。背面、定制能力、刺绣/材质等未知事实不能凭空增加。每张主要文案方向与用途独立，精确文字与摄影画面分离。

## 专业视觉策划
不是扩写一句用户需求。先定义“买家看完该模块应理解什么”，每模块只讲一个有证据的核心信息，再选择视觉叙事：
- Hero：产品单一视觉主角，清楚轮廓和前中后景，用真实语境表达情绪，不把商品挤到背景。
- 结构细节：选择有事实依据的领口、袖口、印花或接缝，以恰当尺度和光线表达，不造面料微观结构。
- 使用场景：人物与环境服务于商品，透视、接触阴影、遮挡和布料受力一致，避免悬浮抠图或贴图感。
- 使用/定制流程：明确步骤与结果关系，原生说明交给排版工具，不让模型编造表单文案。
- 功能/对比：只有证据足够才表达，不虚构性能、认证或竞品比较。
各模块采用适合自身用途的景别、主体位置和空间关系，不连续复制同一张海报。

## 两个锁与逐模块Prompt
商品身份锁只取真实参考和已确认资料：颜色分布、图案、Logo、原文字/号码、领袖/肩线/下摆、版型；未知背面、材质和授权不补造。场景或竞品参考不决定我方商品。
整套风格锁明确配色角色、光源方向与柔硬度、对比、背景材质、景深及排版气质。不同模块能换构图，不能随意变商品外观或摄影体系。personal_experience只是风格参考，本次要求和商品事实优先。
配色统一不代表每张都是同一暗灰渐变背景：根据目的分配主视觉底色、明亮中性细节底和自然场景光，形成明暗、景别与信息密度节奏。高级感来自克制构图、真实光影与清晰焦点，不是统一压暗或反复加橙色光晕。
composition写明主体占画面关系、位置、景别/视角、前中后景、焦点和安静留白，不能只有“高级、好看、高清”。
每个image_prompt都是独立可执行的摄影/编辑指令，必须自足，不能用“参考上一模块”代替：
1. 每张参考的角色，真实产品与场景/风格来源分开。
2. 当前模块唯一卖点和具体画面安排，不靠虚构文字或特效。
3. 主光、补光、边缘分离、自然阴影、面料视觉质感，不改真实配色。
4. 空间透视、尺度、接触阴影、遮挡和布料褶皱的自然融合。
5. 桌面/移动关键内容安全区与排版留白，规格来自工具规则，不照搬第三方固定尺寸。
6. 禁止新增版面标题、段落、价格、促销或水印；商品自身文字、Logo、号码仍需保留，不能因“无文字画面”删掉。
单模块反馈只修正对应module_id的构图与Prompt，其他模块和共享锁保持不变；明确要求改整套风格时才修改共享锁。
