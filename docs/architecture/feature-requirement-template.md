## 用户操作流程

按进入页面、输入/上传、参数选择、提交、系统处理、查看结果、下载/重试/编辑的顺序描述。

## 输入与输出

- 输入：文本、图片、文件、模板、参考图顺序、参数、批量限制、数量与大小限制。
- 输出：数量、尺寸、格式、命名、文案、提示词、草稿、素材中心和生成历史归档。

## AI 与提示词

说明 AI 策划、图片生成/编辑、多图参考、视觉分析、Prompt Builder、用户可编辑范围和不可覆盖规则。长提示词放入独立 Prompt Builder 或文件，不写进 React 组件。

## 异步任务

说明操作与批次关系、子任务拆分、默认并发、暂停/取消/重试、部分失败、刷新恢复和 Worker 恢复。multiuser 模式统一走服务端 Celery 与 Redis，不在 React 中循环调用外部生图 API。

## 权限

## 数据、接口与页面

- 数据模型：新增/修改表、可选字段、Alembic 迁移、旧数据兼容。
- 接口：请求/响应、错误码、幂等键、权限、额度预估、任务查询。
- 页面：入口、路由、布局、按钮、状态、空/加载/错误状态、移动端、暗色模式。

## 历史与素材

说明项目、版本、输入/输出归档、素材复用、批量下载、删除以及对象存储文件生命周期。

## 异常处理

至少覆盖未登录、无权限、额度不足、输入缺失、格式错误、上传失败、模型不支持、无可用 Key、上游限流、超时、Worker 异常、服务重启、空结果、部分失败、重复提交和取消。

## 测试与验收

至少覆盖 Prompt Builder、参数、权限、额度预占、成功结算、失败退款、任务拆分、并发、幂等、数据隔离、页面状态和原功能回归。验收步骤必须可执行，并验证任务 ID、离页运行、进度恢复、素材归档、额度结算、失败重试和跨用户隔离。

## 实施输出

开发前给出复用清单、数据库/接口/任务/额度/权限影响、文件清单、风险与兼容性、所属 Phase、测试与验收；完成当前可运行阶段并验证后，再继续下一阶段。
